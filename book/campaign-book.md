# Deprecated compatibility alias: campaign book

`campaign-book` and `book/campaign-book.md` are deprecated compatibility aliases
for installed v0.1/v0.2 workspaces. New installations and documentation use the
`production-book` declaration at `book/production-book.md`.

This alias resolves to the same production-book responsibilities and preserves
the project → episode → scene → shot → asset graph. It does not define a flat
campaign data model.
