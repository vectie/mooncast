# Systematic production acceptance

The v2 exit fixture must prove:

- 180–480 second bounds and ordered G0–G7 gates;
- rights and budget failures close production;
- project → episode → scene → shot lineage survives restart;
- deterministic provider routing creates immutable assets within budget;
- a 3-minute MP4 has H.264 video, audio, an embedded subtitle stream, visible
  AI labels, SHA-256 provenance, and the full shot timeline;
- rejected QC blocks G5 and a corrected review can recover;
- client acceptance gates delivery;
- the package remains explicitly not published;
- UI-shaped calls can create, advance, generate, assemble, review, and deliver.
