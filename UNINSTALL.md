# Uninstall

Remove the MoonSuite pack registration, app entrypoints, schedules, and active
pack pointer. Stop the `cmd/studio` process and remove only reproducible build
outputs such as `ui/rabbita-mooncast/dist` and `_build` when desired.

Do not remove the configured `MOONCAST_DATA_ROOT`. Preserve briefs, source
rights, prompts, generations, provenance, reviews, deliveries, publications,
authority attestations, and append-only audit records. Uninstall never invokes
the retired application host or uses it to migrate user-owned evidence.

Also preserve v2 project snapshots, append-only project events, episode/scene/
shot graphs, bibles, scripts, storyboards, animatics, budgets, provider routes,
masters, subtitles, gate receipts, client acceptance, analytics, and economics.
Preserve the MC-7 legacy `application/handoff`, `application/learning`, and
immutable record roots byte-identically, as well as the new
`application/handoff-outbox`. Uninstall never treats a MoonBook import receipt
as permission to delete the original user-owned evidence.

Reinstalling or upgrading may point a new native `cmd/studio` build at the same
data root only after its declared migration has been reviewed. Rabbita bundles
are stateless presentation artifacts and may be regenerated safely.
